The SDK gives you a small set of building blocks for describing work, running it, and finding the results. Choose a goal below to go straight to the relevant documentation.

## A typical path

1. Install the SDK with the [installation guide](../how-to/installation.md).
2. Create a project and run a first Python function with the [quickstart](../tutorials/quickstart.md).
3. Choose a runtime using the [runtime comparison](choosing-a-runtime.md).
4. Use the [reference](../reference/index.md) when you need exact parameters or API behavior.

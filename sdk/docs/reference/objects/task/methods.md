# Task object

The `Task` object provides CRUD methods inherited from its entity base class and methods for managing runs.

## CRUD methods

- `save()`: Save or update the task in the backend.
- `export()`: Export the task locally as a YAML file.
- `refresh()`: Refresh the task from the backend.

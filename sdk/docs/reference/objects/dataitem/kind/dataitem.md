# Dataitem

The `dataitem` kind stores a generic dataset in an addressable repository. Use it when you need to manage data without the additional behavior of a specialized kind.

## Dataitem spec

The `dataitem` kind has the following specification parameters.

| Parameter | Type | Description | Default |
| --- | --- | --- | --- |
| [`path`](../../../configuration/paths/overview.md#entity-paths) | *str* | Target path to the dataitem, either on the local filesystem or in remote storage. | *required* |

## Dataitem methods

The `dataitem` kind has no additional methods.

# Upgrading DigitalHub

## Upgrade notes for release 0.16

You can find the full [Platform release notes here](https://github.com/Calcagiara/digitalhub/releases/tag/digitalhub-0.16.0).

**Core database migration**

With version 16 of the platform, Core uses a script that migrates the database to a new schema, a needed procedure as there have been heavy changes to it. However, your platform version must be at least version 15 before proceeding to upgrade it (so, for example, an upgrade from version 14 to version 16 won't work as intended), so be sure to align the environment with the requirement. 
All running processes generated by Core must be stopped before upgrading.

Read the full [Core release notes](https://github.com/scc-digitalhub/digitalhub-core/releases/tag/0.16.0) for more details.

## Upgrade procedure

Once the platform is installed, you may find yourself in need of tweaking it and upgrading it.

With the command `helm upgrade` you will be able to change the values of the platform with your custom ones like the example below:

```sh
helm upgrade -n <NAMESPACE> <RELEASE> digitalhub/digitalhub --timeout 30m0s --values <YOUR_VALUES_FILE_PATH>
```

**Upgrading Coder templates**

If you wish to upgrade the Coder templates, you can do so.

You can find them in `digitalhub/charts/digitalhub/confs/coder`.

However, it is mandatory to create and set your Coder access token in the values file.

```yaml
coder:
  template:
    upgrade:
      # Set it to true if you want to upgrade the Coder templates.
      enabled: false
      # In order to upgrade the templates, you will need to create and set here a Coder Token.
      token: ""
```
